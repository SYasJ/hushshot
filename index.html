Frequently asked questions

Are my files uploaded anywhere?

No. RedactIt has no server. OCR, face detection and barcode scanning run inside your browser tab, and a strict Content-Security-Policy blocks the page from sending your file anywhere. Open your browser's Network tab and check — dropping a file causes zero requests.

Can the blur be reversed?

Pixels are averaged into large blocks with random noise before any smoothing, so the detail is discarded, not hidden. For maximum certainty pick Blackout, which replaces the area with a solid fill.

Does it remove EXIF, GPS and other metadata?

Yes. The export is re-encoded from raw pixels, so EXIF, GPS coordinates, camera serial numbers, XMP, IPTC and PDF author info are never copied — and the saved file is re-opened and checked.

How do I redact a PDF?

Drop it here. Every page is rendered, sensitive text is detected and hidden, and the pages are flattened into a new PDF, so the text beneath a redaction no longer exists. (Up to 60 pages; the output isn't text-selectable.)

What does it detect?

Credit cards (Luhn-checked), SSNs and tax IDs, emails, phone numbers, street addresses and postcodes, account/routing/IBAN/policy numbers, labelled dates of birth, API keys and passwords, faces, barcodes and QR codes. Names aren't auto-detected — drag a box over anything it missed.

Does it work offline?

Yes. All models, WebAssembly and fonts are bundled with the app, so once the page has loaded you can disconnect and keep redacting.
